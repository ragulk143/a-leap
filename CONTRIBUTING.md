# Contributing to A-LEAP

A-LEAP is currently under active, heavy development. We are building the core asynchronous engine right now!

## How to Help
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-engine`).
3. Commit your changes.
4. Open a Pull Request.

Feel free to open issues to discuss architecture designs, memory tracking mechanisms, or CUDA optimizations!
